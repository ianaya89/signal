why signal

eight reasons, no illustrations

playback01

Bit-perfect, and it proves it

libmpv with exclusive device mode and automatic sample-rate switching. The inspector shows the whole audio path stage by stage — file, decode, dsp, output, device — so "bit-perfect" is a verifiable claim, not a marketing badge.

  • gapless playback
  • ReplayGain track/album
  • FLAC · ALAC · WAV · AIFF · AAC · MP3 · OGG · Opus
keyboard02

Keyboard-first, mouse optional

Vim-influenced normal mode, a mode stack that hands the keyboard to overlays cleanly, and a fuzzy command palette on ⌘k. The ? overlay is generated from the binding registry itself, so it never drifts from what the app actually does.

  • j/k · gg/G · ctrl+d/u everywhere
  • every visible action shows its key
local-first03

Your files, your disk, your database

Multi-root scanning with an fs-watcher, SQLite + FTS5 search, metadata read and written straight to the tags. One database file you can back up, inspect, or delete. Works fully offline; nothing is uploaded.

  • m3u import · multi-genre · VA detection
  • tag write-back from the metadata editor
scriptable04

A control socket and a real CLI

Signal speaks newline-delimited JSON over a Unix socket and ships a signal binary on top of it. Anything that can write to a socket can drive the player — Raycast, tmux statuslines, Stream Deck, shell scripts.

  • signal status --json
  • play · add · seek · vol · next · queue · search
library health05

A doctor for the mess in /music

Real libraries rot: renamed folders, duplicate rips, dead paths. The doctor view finds missing files and relinks them, resolves duplicates, prunes what's gone, and fetches missing cover art.

  • relink moved files by content
  • per-folder removal without touching disk
discover06

Recommendations from your own signal

On repeat, rediscover, from your artists, never played — all computed with plain SQL over your ratings, favorites, play counts and history. No model, no cloud, no one profiling you.

  • ✦ like / ✦✦ love · ♥ favorites
  • smart playlists from rule sets
window modes07

Full pane grid, mini bar, or a pulse

One keypress collapses the whole app into a mini player, and another into a chrome-less 76px dot that floats over the desktop pulsing to the music. Position is remembered per mode.

  • full ⇄ mini ⇄ pulse, always-on-top
craft08

Two themes, both deliberate

Periwinkle-on-indigo for the night, warm manila paper with sealing-wax accents for the day. Square corners, hairline borders, monospace everywhere, a 0ms default animation budget — density over decoration.

  • ListenBrainz scrobbling built in
  • values shown raw: 44.1kHz, not "CD Quality"

why it mattersipc

The player is a daemon you can talk to

The socket lives at $SIGNAL_SOCKET or in the app data dir. Every command the UI can run is reachable from a shell, which means Signal composes with the tools you already have instead of asking you to live inside it.

  • · tmux / starship statusline showing what's playing
  • · Raycast or Alfred hotkeys for play, skip, volume
  • · Stream Deck buttons wired to plain shell lines
  • · cron job that queues an album at 09:00

install

one line, or a file from the releases page

sh · installer 
$ curl -fsSL https://ianaya89.github.io/signal/install.sh | sh
  • · macOS — mounts the dmg, copies Signal.app to /Applications, clears the quarantine flag
  • · Debian/Ubuntu — installs the .deb through apt, which pulls libmpv
  • · other Linux — drops the AppImage in ~/.local/bin/signal-app
  • · no release published yet? it says so and prints the build steps

The dmg carries libmpv and its ffmpeg tree inside Contents/Frameworks, so it runs without Homebrew. It is ad-hoc signed, not notarized — the installer strips the quarantine attribute for you; a manual download needs right-click → Open once.

build it

macOS & Linux · ~5 min from clone to running

first time · zsh 
$ git clone https://github.com/ianaya89/signal
$ cd signal

# rust toolchain via mise, + libmpv
$ mise trust && mise install
$ pnpm install
$ brew install pkgconf mpv

# run it
$ pnpm tauri dev

# the cli
$ cargo build -p signal-cli
